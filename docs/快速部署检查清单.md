# AWS智能定价助手 - 快速部署检查清单

本检查清单帮助您快速完成AWS智能定价助手的部署。按顺序完成每个步骤。

## 📋 部署前准备

### ✅ 工具安装检查

- [ ] **AWS CLI** 已安装并配置
  ```bash
  aws --version
  aws configure
  ```

- [ ] **Python 3.11+** 已安装
  ```bash
  python3 --version
  ```

- [ ] **Git** 已安装
  ```bash
  git --version
  ```

- [ ] **Docker** 已安装（如使用ECS）
  ```bash
  docker --version
  ```

### ✅ AWS账户准备

- [ ] AWS账户已创建并激活
- [ ] IAM用户/角色已配置必要权限
- [ ] **Bedrock访问已申请**
  - 进入AWS控制台 → Bedrock → Model access
  - 申请 Claude 3.5 Sonnet 访问权限
  - 等待审批（通常立即通过）

- [ ] EC2密钥对已创建
  ```bash
  aws ec2 create-key-pair \
    --key-name aws-pricing-assistant-key \
    --query 'KeyMaterial' \
    --output text > ~/.ssh/aws-pricing-assistant-key.pem
  chmod 400 ~/.ssh/aws-pricing-assistant-key.pem
  ```

### ✅ 代码准备

- [ ] 代码仓库已克隆
  ```bash
  git clone <repository-url>
  cd aws-pricing-assistant
  ```

- [ ] 环境变量文件已配置
  ```bash
  cp .env.example .env
  # 编辑 .env 文件
  ```

## 🚀 部署步骤

### 步骤1: 基础设施部署 (10-15分钟)

- [ ] 设置环境变量
  ```bash
  export AWS_REGION=us-east-1
  export STACK_NAME=aws-pricing-assistant
  export ENVIRONMENT=production
  export INSTANCE_TYPE=t3.medium
  export KEY_PAIR_NAME=aws-pricing-assistant-key
  ```

- [ ] 执行基础设施部署
  ```bash
  ./scripts/deploy_infrastructure.sh
  ```

- [ ] 记录CloudFormation输出
  - ALB URL: ___________________________
  - Frontend Bucket: ___________________________
  - Quote Bucket: ___________________________
  - KB Bucket: ___________________________
  - EC2 Instance ID: ___________________________

### 步骤2: DynamoDB表创建 (2-3分钟)

- [ ] 创建所有DynamoDB表
  ```bash
  ./scripts/setup_dynamodb.sh
  ```

- [ ] 验证表已创建
  ```bash
  aws dynamodb list-tables
  ```

### 步骤3: Bedrock Knowledge Base设置 (5-10分钟)

- [ ] 上传知识库数据到S3
  ```bash
  python3 scripts/setup_knowledge_base_s3.py
  ```

- [ ] 创建Bedrock Knowledge Base
  ```bash
  python3 scripts/create_bedrock_knowledge_base.py
  ```

- [ ] 记录Knowledge Base ID
  - KB ID: ___________________________

- [ ] 更新 `.env` 文件
  ```bash
  BEDROCK_KNOWLEDGE_BASE_ID=<your-kb-id>
  ```

### 步骤4: EventBridge爬虫配置 (3-5分钟)

- [ ] 设置爬虫定时任务
  ```bash
  ./scripts/setup_eventbridge_crawler.sh
  ```

- [ ] 验证Lambda函数已创建
  ```bash
  aws lambda list-functions | grep crawler
  ```

### 步骤5: 后端部署 (5-10分钟)

- [ ] 选择部署方式（EC2或ECS）

**EC2部署**:
- [ ] 设置部署变量
  ```bash
  export DEPLOYMENT_TYPE=ec2
  export EC2_INSTANCE_ID=<从步骤1获取>
  ```

- [ ] 执行后端部署
  ```bash
  ./scripts/deploy_backend.sh
  ```

**ECS部署**:
- [ ] 设置部署变量
  ```bash
  export DEPLOYMENT_TYPE=ecs
  export ECS_CLUSTER=aws-pricing-assistant-cluster
  ```

- [ ] 执行后端部署
  ```bash
  ./scripts/deploy_backend.sh
  ```

### 步骤6: 前端部署 (3-5分钟 + 15-20分钟CloudFront)

- [ ] 设置前端变量
  ```bash
  export BACKEND_API_URL=<从步骤1获取ALB URL>
  export S3_BUCKET=<从步骤1获取前端存储桶>
  export CLOUDFRONT_ENABLED=true
  ```

- [ ] 执行前端部署
  ```bash
  ./scripts/deploy_frontend.sh
  ```

- [ ] 记录CloudFront URL
  - CloudFront URL: ___________________________

### 步骤7: CloudWatch日志配置 (1-2分钟)

- [ ] 配置日志组
  ```bash
  python3 scripts/setup_cloudwatch_logs.py
  ```

### 步骤8: 生成安全密钥

- [ ] 生成JWT密钥
  ```bash
  python3 -c "import secrets; print(secrets.token_urlsafe(32))"
  ```
  - JWT Secret: ___________________________

- [ ] 生成加密密钥
  ```bash
  python3 scripts/generate_encryption_key.py
  ```
  - Encryption Key: ___________________________

- [ ] 更新Secrets Manager
  ```bash
  aws secretsmanager update-secret \
    --secret-id aws-pricing-assistant-secrets \
    --secret-string '{
      "JWT_SECRET_KEY": "<your-jwt-secret>",
      "ENCRYPTION_KEY": "<your-encryption-key>"
    }'
  ```

## 🆘 常见问题快速解决

### Bedrock访问被拒绝
```bash
# 解决方案：申请模型访问权限
# AWS控制台 → Bedrock → Model access → 申请Claude 3.5 Sonnet
```

### DynamoDB表已存在
```bash
# 解决方案：跳过或删除后重建
aws dynamodb delete-table --table-name <table-name>
```

### 无法访问EC2实例
```bash
# 检查安全组
aws ec2 describe-security-groups --group-ids <sg-id>
# 检查实例状态
aws ec2 describe-instances --instance-ids <instance-id>
```

### 前端无法加载
```bash
# 检查后端URL配置
cat frontend/config.js
# 清除CloudFront缓存
aws cloudfront create-invalidation --distribution-id <dist-id> --paths "/*"
```
